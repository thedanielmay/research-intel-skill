# research-intel skill

Deep, multi-source intelligence research on a named company or a non-company topic.

This skill merges the former company-intel and topic-intel skills into one router. It
covers entity verification, financial and legal intelligence, people profiling, digital
footprint, market and industry research, policy and regulation, academic fields,
technology categories, trends and public figures. Both research paths share one
intelligence standard, one four-layer web access protocol and one anti-hallucination
protocol: cite before you write, quarantine every number, run the fabrication detection
pass, and interpret every gap. Detailed procedures live under
`skills/research-intel/references/company/` and
`skills/research-intel/references/topic/`. Shared rules live in
`skills/research-intel/references/shared/`.

## Install

Install as a plugin:

```
/plugin install research-intel --marketplace thedanielmay/research-intel-skill
```

Or link the folder into your skills directory:

```
ln -s /path/to/research-intel-skill/skills/research-intel ~/.claude/skills/research-intel
```
